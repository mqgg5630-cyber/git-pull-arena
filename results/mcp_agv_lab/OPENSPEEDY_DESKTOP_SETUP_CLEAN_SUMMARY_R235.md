```text
OPENSPEEDY_DESKTOP_READY
```

## 安装位置

桌面目录：

```text
D:\桌面
```

OpenSpeedy 文件夹：

```text
D:\桌面\OpenSpeedy
```

主程序：

```text
D:\桌面\OpenSpeedy\app\openspeedy.exe
```

## 一键运行方式

桌面上已经创建：

```text
D:\桌面\OpenSpeedy.lnk
```

也创建了：

```text
D:\桌面\OpenSpeedy.bat
```

你直接双击桌面上的 `OpenSpeedy` 快捷方式或 `OpenSpeedy.bat` 即可运行。

## 管理员运行方式

如果普通运行无法影响目标进程，可以使用管理员运行脚本：

```text
D:\桌面\OpenSpeedy\Run-OpenSpeedy-as-Admin.bat
```

双击后会弹出 UAC，点允许即可。
